# NaVVA project page

Source of https://navva-project.github.io/ : the public page for *From Narratives of Value to Valuable Algorithms: computational modelling of national identity in British television advertisements (2016–2026)*, a King's College London × BFI doctoral project (AHRC Collaborative Doctoral Partnership).

- `index.html` is the project page.
- `upgrade.html` is the PhD upgrade presentation (December 2026), served at https://navva-project.github.io/upgrade.html. It is a single file with ten pages; use the tabs or the left and right arrow keys to move between them. Figures marked "illustrative" are for illustrative purposes only and do not report results.
- `assets/navva_card.png` is the title card, rendered from `_src/card.html` at 1480×960. `_src/concepts.html` holds the earlier concept sketches for the masthead image.

The code for corpus construction is in a separate repository: https://github.com/SH-Skylar-Liu/advert-silence-boundary
